# メトリクス

中国語版（完全版）：[metrics.md](./metrics.md)

本システムは **交付効率 + 流動の健全性 + 品質リスク + 計画の信頼性 + 開発効率** を中心に、データ可用性に応じて段階的に算出します。

## 分類

### 交付・流動

- スループット
- 交付サイクル（p50/p75/p95）
- 処理サイクル（p50/p75/p95）
- 平均 WIP / 老化 WIP

主データ：プロジェクト管理（`data_source`）

### 品質

- 欠陥関連シグナル（要件/開発/テスト）
- 欠陥率、再オープン率
- 欠陥逃逸（件数と率）

主データ：欠陥管理（`bug_source`）+ プロジェクト管理（`data_source`）

### 計画の信頼性

- コミット達成率
- スコープ変更
- イテレーションのスループット/完了率/持ち越し（任意）

主データ：プロジェクト管理（`data_source`）

### 開発効率

- PR サイクル、レビュー待ち時間
- 変更規模分布

主データ：Git（`git_source`）

### CI / 品質ゲート

- CI 頻度、成功率
- コードスキャン合格率

主データ：CI（`ci_source`）

## 閾値

閾値は `work/meta/config.yaml` の `metrics.targets` を参照します。
